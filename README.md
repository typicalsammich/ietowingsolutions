# Towing Solutions Website

Static multi-page website for Towing Solutions, Perris CA.

## Included
- 26 indexable pages
- All 17 service pages from the current Towing Solutions site
- EN / ES site-wide language switch powered by Google Translate, persisted across pages
- Mobile navigation and persistent mobile call CTA
- FAQ page plus service-specific FAQs
- LocalBusiness, Service and FAQ structured data
- Open Graph, canonical, sitemap and robots SEO foundations
- Instagram, Facebook, Yelp and Google Review buttons in the footer

Deploy the contents of this folder to Vercel, Netlify, GitHub Pages, or any static host.
